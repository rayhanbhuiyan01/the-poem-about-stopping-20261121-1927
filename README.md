A tiny Python program that writes a short, hand-written poem about stopping: the speaker asks someone to act on their behalf, then takes the doing back, and discovers that holding still — leaving the message unsent and the door shut — is itself a choice with weight, a road chosen by standing still.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` by default (or the directory in `OUTPUT_DIR`, or a path passed as the first argument) and prints how many characters it wrote.
